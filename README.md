# AC200L
code plc s7-1200,

Thứ tự các network
1: Analog scale
2: Manual mode
3: StartupFill
4: Alarm
5 Program Select
6: StartPrecheck
7: Auto run
8: Door Control
9: Systerm Output

PID sử dụng: PID_Compact V3.0
Setpoint: %MD112 "HMI_Temperature_SP"
Input: Input : %MD124 "HMI_Temperature_PV"
Output: Output_PWM
